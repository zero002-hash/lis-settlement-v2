# 위키 작성 규칙 적용

위키 문서를 쓰거나 고치기 전에 `docs/wiki-writing-rules.md`를 읽고 20개 규칙을 그대로 따른다.

## 절차

1. `docs/wiki-writing-rules.md`를 읽는다.
2. 대상 위키 페이지의 최신본을 다시 읽는다(사용자가 직접 고쳤을 수 있음).
3. 규칙에 맞춰 초안을 작성하고, 수정 요청이면 바로 반영한다.
4. 문서 유형에 따라 도입부를 결정한다(상위 기획/세부 정책은 "~란? / 왜 필요한가", 상세 기획/세부 기획 기능 명세는 생략).
5. 위키를 업데이트할 때마다 페이지 댓글에 "이전 내용 / 수정한 내용"을 남긴다.
6. 같은 스펙이 걸린 로컬 코드와 연관 문서를 확인하고, 코드를 바꾸기 전에 어떤 파일을 바꿀지 알린다.
7. 마지막에 변경 요약, "(미확인)" 항목, 질문 순으로 보고한다.

## 자주 틀리는 점

- 하이픈과 대시를 쓰지 않는다. 화살표 "->"만 허용한다.
- 문단 사이에 빈 줄을 넣지 않는다(줄바꿈 한 번).
- 굵은 라벨 대신 h3을 쓴다.
- 중첩 불릿을 쓰지 않는다.
- 약칭을 쓰지 않는다('센터/톡' 금지).
- 확정되지 않은 정책은 "(제안)", 확인되지 않은 사실은 "(미확인)"을 붙인다.
