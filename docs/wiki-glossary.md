# 위키 용어집

위키 문서에서 쓰는 확정 용어. 새 용어는 제안 -> 사용자 확정 후 이 표에 등록함(규칙 27).

| 사용 | 쓰지 않음 | 비고 |
| --- | --- | --- |
| 용차 기사 | 정보망 기사 | 2026 결정. "정보망배차", "정보망유형"은 원복되어 그대로 사용 |
| 정보망배차 | 용차배차 | 화면 표기 그대로 |
| 확인 / 확인여부 | 마감완료, 확정(금액 단계) | 매출장부 금액 확인 용어 통일(2026-07-06) |
| 청구금액확인, 배차금액확인 | 금액확정 | 매출 상태 전환 조건 용어 |
| 거래처 | 화주(화면 일반 지칭) | 화주는 역할명(화주 배차 담당자 등)에서만 사용 |
| 거래명세서 확정 / 확정 취소 | (확인으로 바꾸지 않음) | 알림 유형명과 템플릿명은 화면, 템플릿 표기를 그대로 씀(2026-10-06 결정). 위 "확인" 통일은 매출장부 금액 단계에 한함 |
| 알림센터, 알림톡 | 센터/톡 | 채널 풀네임 표기(규칙 5) |
| 세부 기획 | 상세 기획 | 문서 유형명(규칙 23) |
